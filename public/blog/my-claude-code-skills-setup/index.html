My Claude Code skills setup

Rishabh Sharma · 11 November 2026 Draft

I do most of my coding with an AI agent, and the difference between chaos and shipping is a skill stack — small playbooks the agent follows every time, instead of improvising.

Explore → Plan → Code → Verify → Commit

That is the loop. Explore the code first, write the plan, then write the smallest complete change. Verification comes before every push: build, tests, a secret scan, and a check that the remote HEAD has not moved under me.

Feedback becomes rules

After every multi-step task I run a feedback pass: what went wrong, what the lesson is, and where the lesson lives so the next session reads it. A log entry alone is not a fix — a mistake is closed only when the lesson reaches the place it will be read next time.

What I use it for

Daily open-source PRs, the SafeLife 30-day upgrade program, my portfolio, and outreach automation. The agent does the repetitive work; I make the decisions.
