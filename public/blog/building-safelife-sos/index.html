Building SafeLife SOS

Rishabh Sharma · 11 November 2026 Draft

SafeLife started from a simple question: if something goes wrong, how fast can help reach you? The answer became an emergency SOS app with live location tracking, guardian alerts, and a Telegram bot that pings the people who need to know.

The stack

Expo and React Native for the app, Node.js and Express for the backend, Supabase for auth and data, Upstash and QStash for background jobs. Google sign-in for auth. No interim APKs — one final release after a 30-day build program.

What was hard

Rate limits matter when the feature is an emergency: SOS is capped at 30 requests per 15 minutes per IP so it cannot be spammed. Guardian onboarding uses a 6-digit salted-hash code with a 10-minute expiry — 5 wrong attempts kills the code.

What is live

Google login works, SOS is confirmed working, and the Telegram bot is verified live. SMS, WhatsApp and push alerts are still blocked on API keys and verification — the honest state of the project, not a finished story.
